Learn about Web Client and Server Interaction!

When a web client enters the website name into a browser, the name is resolved by a DNS server to an IP address. When the client receives the IP address, the client browser uses that IP address and port 80 to request the web service. This request is sent to the server using the Hypertext Transfer Protocol (HTTP).

When the server receives the port 80 request, the server will respond to the client request by sending a web page to the client.

The information content of this web page is encoded using a specialized mark-up language.

HTML (Hypertext Mark-up Language) is a popular language for the web, and is currently used with this web service. However, other languages also exist, such as XML and XHTML. These are gaining popularity.
